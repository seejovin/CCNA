# IP Connectivity: Sets 09–10

Fifty additional original questions complete the nine-set IP Connectivity allocation: 25 questions per set, each with 21 single-answer, three select-two and one matching item. Both sets assess parents 3.1–3.5. Existing Set 01 questions were preserved.

Cases distinguish valid route candidates, installed prefixes and destination forwarding; IPv4 and IPv6 static route scope; recursive and link-local next-hop resolution; OSPF costs, neighbors and elections; and first-hop redundancy behavior. Keys and per-option explanations were reviewed against Cisco routing and OSPF documentation, RFC 1812, RFC 2328 and RFC 9568. The address-conflict case also cites RFC 5227. Each question contains its specific reference and relevant section.

Independent review recalculated route selection, subnet boundaries, OSPF path costs and election conditions. It identified and corrected a bare `::1` shorthand that could mean the IPv6 loopback address, maintenance wording that confused continued gateway service with tolerance of an additional failure, and adjacency child tags on cost-only OSPF items.

A repetitive shared-LAN failure item was replaced with a virtual-gateway address conflict scenario. A neighbor-versus-route-installation case now asks for two explicitly distinct conclusions. Multiple-answer and matching keys were remapped with their choice order during authoring.

Exhibits are constructed educational cases, not results from device-lab execution. Editorial review and numerical checks do not establish measured exam difficulty or a guaranteed result.
